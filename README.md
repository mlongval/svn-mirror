# VICE GitHub Mirror
This is the official git mirror of the [VICE subversion repo](https://sourceforge.net/p/vice-emu/code/HEAD/tree/).

For news, documentation, developer information, [visit the VICE website](https://vice-emu.sourceforge.io/).

## VIC-II Kawari Branch

The [`kawari-merge`](../../tree/kawari-merge) branch adds emulator support for the
[VIC-II Kawari](https://github.com/randyrossi/vicii-kawari) FPGA chip, merged from
Randy Rossi's vicii-kawari-vice fork onto current VICE trunk.
See [`vice/src/viciisc/KAWARI.md`](../../blob/kawari-merge/vice/src/viciisc/KAWARI.md) for status and details.

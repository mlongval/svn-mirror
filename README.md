# VICE + VIC-II Kawari Fork

This is a fork of the [VICE-Team/svn-mirror](https://github.com/VICE-Team/svn-mirror) git mirror of VICE,
adding emulator support for the [VIC-II Kawari](https://github.com/randyrossi/vicii-kawari) FPGA chip.

For news, documentation, developer information, [visit the VICE website](https://vice-emu.sourceforge.io/).

## VIC-II Kawari Branch

The [`kawari-merge`](../../tree/kawari-merge) branch adds VIC-II Kawari support to `x64sc` and `xscpu64`,
merged from Randy Rossi's vicii-kawari-vice fork onto current VICE trunk.
See [`vice/src/viciisc/KAWARI.md`](../../blob/kawari-merge/vice/src/viciisc/KAWARI.md) for status and details.
